🇹🇷 TÜRKÇE

1. Genel Bilgi

Bu Gizlilik Politikası, Şantiye Puantaj Defteri mobil uygulaması (“Uygulama”) için geçerlidir. Uygulama, şantiye ve personel puantaj kayıtlarının tutulması ve dosya yönetimi amacıyla geliştirilmiştir.

2. Toplanan Veriler

  • E-posta adresi
  • Kullanıcı şifresi (Firebase Authentication üzerinden güvenli şekilde işlenir)
  • Kullanıcının yüklediği dosyalar ve belgeler

3. Dosya Erişimi

Uygulama, yalnızca kullanıcı tarafından seçilen dosyaları eklemek için dosya erişim izni kullanır. Kullanıcı seçimi dışında cihaz dosyalarına erişilmez.

4. Verilerin Kullanım Amaçları

  • Kullanıcı hesabı oluşturma ve giriş
  • Puantaj kayıtlarının saklanması
  • Dosya ve belge ekleme işlemleri
  • Veri kaybını önlemek

5. Veri Saklama

Veriler Google Firebase altyapısında saklanır:

  • Firebase Authentication
  • Firebase Database / Firestore
  • Firebase Storage (dosya yükleme kullanılıyorsa)

6. Veri Paylaşımı

Kullanıcı verileri satılmaz ve reklam amaçlı paylaşılmaz. Yalnızca yasal zorunluluk halinde veya altyapı hizmeti kapsamında Firebase ile teknik olarak işlenir.

7. Veri Güvenliği

  • Güvenli kimlik doğrulama
  • Yetkilendirme kontrolleri
  • Bulut güvenlik altyapısı

8. Kullanıcı Hakları

Kullanıcılar veri görüntüleme, güncelleme ve hesap silme talebinde bulunabilir. İletişim: [emircftc6@gmail.com]

9. Çocukların Gizliliği

Uygulama 13 yaş altı çocuklara yönelik değildir.

10. Güncellemeler

Politika zaman zaman güncellenebilir. Güncel sürüm bu sayfada yayınlanır.

🇬🇧 ENGLISH

1. General Information

This Privacy Policy applies to the Şantiye Puantaj Defteri mobile application (“App”). The App is designed for construction site attendance tracking and document management.

2. Data Collected

  • Email address
  • User password (processed securely via Firebase Authentication)
  • Attendance and site records
  • User uploaded files and documents

3. File Access

The App uses file access permission only to let users select and attach files. No files are accessed without user action.

4. Purpose of Data Use

  • User account creation and login
  • Saving attendance records
  • File and document attachment
  • Preventing data loss

5. Data Storage

User data is stored using Google Firebase services:

  • Firebase Authentication
  • Firebase Database / Firestore
  • Firebase Storage (if file upload is enabled)

6. Data Sharing

User data is not sold or used for advertising. Data may be processed by Firebase infrastructure providers or shared if legally required.

7. Data Security

  • Secure authentication
  • Access controls
  • Cloud security infrastructure

8. User Rights

Users may request data access, correction, or account deletion. Contact: [emircftc6@gmail.com]

9. Children’s Privacy

This App is not intended for children under 13.

10. Updates

This policy may be updated. The latest version will always be published on this page.
